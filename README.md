# gramswarajyamandal.org

Website for **ग्राम स्वराज्य मंडल, सोमेश्वर / Gram Swarajya Mandal, Someshwar (GSMS)**,
built with Jekyll and hosted on GitHub Pages (custom domain in `CNAME`).

- `_events/` — one file per event (shown on Home, Events and Gallery)
- `_projects/` — one file per long-running project (shown on Our Work)
- `images/events/<event>/` — event photos
- `_layouts/`, `_includes/`, `assets/css/style.css` — site design
- `.pages.yml` — form editor setup for https://app.pagescms.org

**To add events, see [EDITING.md](EDITING.md).**
